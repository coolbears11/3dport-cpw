# Deployment Checklist

1. Upload every file and folder from this project root to GitHub.
2. Do not upload `node_modules`.
3. Confirm `app` and `package.json` are visible at the top level of the GitHub repository.
4. Import the GitHub repository into Vercel.
5. Keep framework preset as **Next.js**.
6. Keep root directory as the **repository root**.
7. Keep build command as `npm run build`.
8. Leave output directory blank/default.
9. Deploy.
